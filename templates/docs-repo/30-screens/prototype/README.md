# 프로토타입

화면의 정본이다. 동작하는 화면(HTML · JS 또는 프로젝트가 쓰는 도구의 결과물)을 이 폴더에 둔다. `docs-site/` 는 생성물이라 거기에 원본을 두지 않고, 문서 사이트에도 넣지 않는다 (`docs-site.json` 의 `exclude`. 사이트에는 `../shots/` 스크린샷).

- 화면마다 화면 ID 를 파일 이름이나 화면 위 표시로 붙인다 (`SCR-ORD-01`).
- 서버가 맡을 동작(저장 · 권한 · 동시성)은 예시 값으로 보이고 「서버 책임」 표시를 한다.
- 화면을 바꾸는 결정은 결정 기록을 남기고, 기능 문서 · 화면 목록을 같은 커밋에서 맞춘다.
- 영역 · 요소에 이름표를 달면 구현 쪽 요소 체크리스트(`kedovi screens inventory`)가 정확해진다: 영역 `data-area="오른쪽 패널"`, 요소 `data-el="주문 요약"` (하나라도 `data-el` 이 있으면 그것만 센다). 없으면 제목 · 버튼 · 표 · 차트 · 칩 모양으로 짐작한다.
