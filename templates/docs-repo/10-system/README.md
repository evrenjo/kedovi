# 시스템 구성

> 상태: 초안

서버 아키텍처의 정본이다. 구성도는 **단계별**(1차 오픈 · 2차 …)로 그리고, 서비스 · DB 와 스키마 · 미들웨어 · 외부 서비스 · 서버 사양을 표로 둔다.
양식은 [architecture.md](architecture.md) (워크스페이스에서는 `architecture` 스킬이 순서를 안내한다).

- 구성도는 mermaid 로 그린다. 상자 · 화살표 문자로 그린 ASCII 그림은 쓰지 않는다.
- 테이블 수 · 서버 수 같은 개수는 적지 않는다 (정의서 · 표에서 센다).
- 운영하며 바뀌는 사실(디스크 · 메모리 · CI 러너 · 경로)은 표에 「확인 명령 · 확인일」 칸을 둔다. 확인일이 오래되면 문서 점검이 알린다.
- 구성이 바뀌는 결정은 결정 기록(`DEC-…`)을 남기고 여기서 ID 로 가리킨다.
