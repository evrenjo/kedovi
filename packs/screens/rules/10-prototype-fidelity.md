## 프로토타입 충실도

프로토타입은 **화면과 사용자 흐름**을 확인하는 물건이다. 서버가 맡을 일을 흉내 내는 데 시간을 쓰지 않는다.

| 만든다 | 흉내 내지 않는다 (예시 값 + 「서버 책임」 표시) |
|---|---|
| 화면 배치 · 상태별 모양(빈 값 · 오류 · 로딩) · 화면 이동 · 입력 검증 메시지 | 여러 화면 · 창 사이 상태 정합, 동시성 · 경쟁 조건, 저장 · 재시도 · 권한 판정 |

- 서버 몫인 동작은 예시 데이터로 결과 화면만 보이고, 화면 위나 설명에 `서버 책임: <무엇>` 을 적는다.
- 더 깊이 흉내 내야 확인이 되는 경우(예: 창 사이 동기화를 직접 보여야 함)는 **착수 전에 사용자가 고른다.** 선택지: 예시 반영과 「서버 책임」 표시 (권장) · 실제처럼 동작 (시간 예산과 함께).
- 리뷰를 맡길 때도 이 범위를 지시서에 적는다. 서버 몫 동작의 빈틈은 블로커가 아니다.

## 화면 품질 기준 (설계부터)

구현 뒤 화면 품질 점검(`kedovi screens quality`)이 보는 것을 정본에 먼저 그린다. 설계에 없는 상태 · 문구는 구현에서 제각각 생긴다.

| 영역 | 정본에 그릴 것 |
|---|---|
| 상태 | 서버 요청이 있는 화면마다 불러오는 중 · 데이터 없음 · 오류(다시 시도) · 끊김 · 권한 없음의 모습과 문구 |
| 입력 | 보이는 라벨, 필수 표시, 칸마다 오류 문구(원인 · 고칠 방법), 제출 중 버튼 상태(두 번 못 누름), 되돌릴 수 없는 동작의 확인 |
| 목록 | 검색 · 정렬 · 필터 상태 표시, 페이지 나눔, 긴 값 · 특수문자 처리(줄바꿈 또는 말줄임과 전체 값 보기) |
| 레이아웃 | PC 1280 · 폰 390 모습, 320px 폭에서 가로 스크롤 없음 (표 · 스크롤 영역 예외) |
| 상호작용 · 접근성 | 누르는 영역 24px 이상, 포커스 모양(토큰에), 명도 대비 4.5:1(큰 글자 3:1), 드래그만 되는 기능의 대안, 제목 단계 |

- 다 그리면 `kedovi screens quality <화면 ID> --design` 으로 정본을 측정한다 (대비 · 라벨 · 겹침 · 잘림 · 320px · 200% · 키보드 · 24px). 실패는 정본에서 고친다.
- 수준(공공 · 일반 · 사내 도구)은 `kedovi screens quality-level`. 공공 사업은 KRDS 컴포넌트 · 패턴과 KWCAG 2.2 를 기준으로 그린다.
