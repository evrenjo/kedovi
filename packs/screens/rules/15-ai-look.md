## AI 티 없는 화면 (프로토타입 단계)

화면의 모양은 프로토타입에서 정하고, 구현은 프로토타입과 그 토큰을 따른다 (「프로토타입대로 구현」). 그래서 AI 티는 **프로토타입 단계에서** 뺀다. 구현 단계에서 화면을 새로 디자인하지 않는다.

1. **방향 먼저 (사용자가 따로 부르지 않아도).** 프로토타입을 만들거나 고치기 시작하면 손대기 전에 방향 5줄을 제안하고 승인받는다. 사용자가 「그냥 해」 라고 했으면 방향을 보이고 바로 진행한다.
   - 제품(누가 · 무엇에 쓰나) · 성격(형용사 2~3개) · 세계(닮을 실제 도구 · 매체) · 순간(색을 쓸 한두 곳) · 시그니처(한 번만 쓰는 특징 하나).
   - 그 전에 이 프로젝트의 디자인 시스템 · 아이콘 세트 · 브랜드 색 · 글꼴을 찾아 방향에 넣는다 (구현 repo 의 package.json · 테마 파일). 구현에서 실제로 만들 수 있는 부품으로 그린다.
2. **다듬기.** 언슬롭(unslop) 스킬이 있으면 그 스킬로 한다 (점검 → 방향 → 승인 → 간격 · 색 · 아이콘 · 문구 · 글꼴 · 배치 · 세부 · 그림 · 움직임 순 손질). 이미 잘 된 화면은 다시 디자인하지 않고 작은 다듬기만 한다.
   - **없으면 깔았을 때 얻는 것부터 보이고 권한다** (「설치할까요?」 만 묻지 않는다): 화면을 보고 AI 티를 위치까지 짚음 · 제품에 맞는 방향 제안 · 디자이너처럼 단계별 손질 · 라이브 주소만으로 점검. 지금은 아래 기준과 `kedovi screens slop`(기계로 잡히는 것만)으로 한다는 것도 함께 말한다. 사용자가 좋다고 하면 설치 명령을 실행하고, 새 세션부터 쓰인다고 알린다. 원치 않으면 아래 기준으로 진행한다.
   > Claude Code: `claude plugin install unslop --marketplace heydamir/unslop` (이 PC 의 모든 프로젝트, 팀이 같이 쓰려면 워크스페이스에서 `--scope project`)
   > Codex: 저장소의 `skills/unslop` 폴더를 `~/.agents/skills/` 에 복사 (`$unslop`)
3. **토큰 파일.** 정한 값을 `<화면 폴더>/prototype/tokens.css` 에 CSS 변수로 둔다: 색(중립 단계 · 글자 3단계 · 강조 1 · 상태색) · 간격(4px 단계) · 글꼴(가족 · 크기 · 굵기) · 모서리 · 그림자 · 움직임(시간 · 곡선). 프로토타입은 이 변수만 쓴다. 구현은 이 값으로 테마를 맞춘다.
4. **검사 뒤 확정.** `kedovi screens slop <프로토타입 폴더>` 가 0개이거나 남은 줄마다 이유(`slop-ok` 주석, 예: 브랜드 색)가 있어야 화면을 확정하고 스크린샷을 찍는다.

| 한국어 화면 | 기준 |
|---|---|
| 글꼴 | 한글 글꼴을 먼저 정한다 (예: Pretendard · 프로젝트 글꼴). 본문 14~16px · 줄 간격 1.5 이상 |
| 굵기 | 400 · 500 · 600 (한글은 700 이상이면 뭉쳐 보인다) |
| 문구 | 인사 · 느낌표(「환영합니다!」) 대신 할 일과 결과를 구체적으로. 버튼은 동사(저장 · 내보내기) |
| 숫자 · 날짜 | 표 숫자는 `tabular-nums` · 오른쪽 정렬 · 천 단위 쉼표, 날짜 형식은 화면 정책 하나로 |
| 예시 데이터 | 실제 업무처럼 (그럴듯한 회사 · 금액 · 날짜). Lorem · 123,456 · 같은 이름 반복 금지 |
| 줄바꿈 | `word-break: keep-all` (낱말 중간에서 끊지 않는다) |
