# 사용성 평가 결과서

실제 사용자가 주요 과업을 해 보고, 막힌 곳을 찾아 고친 기록이다. 마일스톤마다 한 번, 화면이 크게 바뀌었을 때 다시 한다.

> 근거: 사용성 평가 결과서 형식은 ISO 25062:2025, 사용 품질 모델은 ISO/IEC 25019:2023. 참여자는 3~5명이면 주요 문제 대부분이 드러난다.

## 평가 개요

| 항목 | 내용 |
|---|---|
| 목적 | <이번 평가로 확인할 것 한두 줄> |
| 대상 | <마일스톤 · 기능 범위> |
| 일시 · 장소 | <날짜 · 대면 또는 원격> |
| 환경 | <PC · 폰, 브라우저, 시험 서버 주소> |
| 진행 | <진행자 · 기록자> |

## 참여자

| # | 역할 · 업무 | 경험 (서비스 · 비슷한 도구) | 비고 |
|---|---|---|---|
| P1 | <예: 주문 담당자> | <처음 · 비슷한 도구 1년> | |

## 과업

과업마다 그 과업이 지나가는 화면 ID 를 적는다. 화면 품질 점검이 화면 ID 로 이 결과서를 찾는다.

| # | 과업 | 시작 조건 | 성공 기준 | 화면 ID | 관련 기능 |
|---|---|---|---|---|---|
| T1 | <예: 지난주 주문 가운데 취소된 것을 찾는다> | <로그인한 상태> | <취소 주문 목록이 보인다> | <SCR-ORD-001> | <FN-ORD-01> |

## 결과

| 과업 | 성공률 | 평균 시간 | 오류 · 막힘 횟수 | 만족도 (1~5) |
|---|---|---|---|---|
| T1 | <4/5> | <1분 20초> | <3> | <4.2> |

전체 만족도는 SUS(시스템 사용성 척도) 10문항 점수로 적는다: <점수> / 100 (68 이상이면 평균 이상).
