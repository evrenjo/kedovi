# AI 자료

AI 가 작업에 참고하려고 모은 자료를 둔다. 사람이 읽는 정본은 docs-site 폴더이고, 이 폴더는 문서 사이트에 올리지 않는다.

## 규칙

| 항목 | 규칙 |
|---|---|
| 폴더 | 성격별 폴더에 넣는다 (예: 조사 · 분석 · 외부 문서 요약). 맨 위에 파일을 두지 않는다 |
| 목록 | 폴더를 만들면 아래 「폴더 목록」 에 한 줄을 더한다 |
| 파일 머리 | 첫 줄에 한 줄 요약 · 날짜(YYYY-MM-DD) · 관련 ID 를 적는다 |
| 사람 문서와의 관계 | 사람 문서는 근거 인용구에 이 자료의 경로만 적는다. 내용을 옮길 때는 사람 글 형식으로 다시 쓴다 |
| 낡은 자료 | 지우거나 머리 줄에 「낡음」 을 단다 |

> 참고: 파일 머리 예시는 「> 결제 대행사 API 비교 · 2026-01-15 · REQ-003」. 규칙 어긋남은 kedovi docs ai-docs 가 알린다.
