# 데이터

테이블 정의서(스키마마다 한 문서)와 이 목록이 짝이다. ERD 는 문서 사이트를 만들 때 정의서에서 그린다. 정의서 순서는 datamodel 스킬이 안내한다.

## 엔티티 목록

| 엔티티 | 테이블 | 기능 ID | 비고 |
|---|---|---|---|

- 테이블 · 컬럼은 기능 ID · 결정 ID 를 근거로 만든다.
- 저장하지 않는 기능은 기능 문서의 데이터 칸에 「없음」 과 이유를 적는다.

## 컨벤션

워크스페이스 설정(datamodel 변수)과 같게 둔다.

| 항목 | 값 |
|---|---|
| DB 종류 | 정하지 않음 |
| 이름 | 정하지 않음 |
| 기본키 | 정하지 않음 |
| 공통 컬럼 | 정하지 않음 |
| 삭제 방식 | 정하지 않음 |
