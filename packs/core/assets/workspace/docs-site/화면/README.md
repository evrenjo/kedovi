# 화면

**화면의 정본은 프로토타입이다** (이 폴더의 prototype). 여기에는 화면 목록과 화면 공통 규칙만 둔다. 배치 · 문구를 다시 쓰지 않는다.

## 화면 목록

| 화면 ID | 화면 | 경로(메뉴) | 기능 ID | 프로토타입 |
|---|---|---|---|---|

- 화면 ID 는 SCR- 로 시작한다.
- 화면 ID 는 한 번 붙이면 바꾸지 않고, 없앤 화면은 결번으로 남긴다.
- 기능 ID 마다 화면이 있어야 한다.
- 화면이 없는 기능은 기능 문서에 「없음」 과 이유를 적는다.
- 화면설계서와 프로토타입 대조는 screens 스킬이 안내한다.
