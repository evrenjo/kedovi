# 개발 표준

> 상태: 초안

코드 repo 에 이미 정한 관례가 있으면 그것이 먼저다. 여기에는 팀이 합의한 것만 짧게 둔다.

| 항목 | 표준 | 검사 |
|---|---|---|
| 브랜치 · 커밋 | 정하지 않음 | 정하지 않음 |
| 코드 형식 | 정하지 않음 | 정하지 않음 |
| 테스트 | 정하지 않음 | 정하지 않음 |
| 리뷰 · 머지 | 정하지 않음 | 정하지 않음 |
| 배포 | 정하지 않음 | 정하지 않음 |

> 참고: 「검사」 칸에는 그 표준을 지키게 하는 도구(린터 · 커밋 훅 · CI)를 적는다. 사람의 기억에 맡기는 표준은 줄인다.
