# 자료실

사람이 참고하는 자료를 둔다. 정본은 설계 · 기능 문서이고, 여기 자료는 그 근거다.

| 폴더 | 내용 |
|---|---|
| [회의록](회의록/) | 회의 하나에 한 문서. 파일 이름은 날짜-주제.md |
| 이 폴더 | 받은 문서 · 참고 자료 · 원격이 없을 때 게시판 글 |

- 회의록 머리에는 날짜와 참석, 결정, 할 일을 적는다.
- 회의에서 정한 것은 설계의 결정 문서로 옮기고 그 ID 를 건다.
- AI 가 작업 중에 모은 자료는 워크스페이스의 ai-docs 폴더에 둔다 (사이트에 올리지 않는다).
