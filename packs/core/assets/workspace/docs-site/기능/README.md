# 기능

기능 하나에 한 문서. 기능마다 명세 → 설계 → 구현 → 검증 → 배포 순서로 진행하고, 문서 머리 줄의 단계를 고친다.

| 번호 | 기능 | 마일스톤 | 단계 |
|---|---|---|---|

- 새 기능은 [틀](_template.md)을 복사해 번호-이름.md 로 만든다 (예: 001-회원관리.md).
- 제목 아래 머리 줄에 번호와 이름, 마일스톤, 단계를 적는다.
- 명세에는 기능 ID(FN-)와 수용 기준(AC-)을 쓴다.
- 설계에는 API ID 와 화면 ID, 테이블 이름을 쓴다.
- 코드와 테스트의 @spec 표시가 이 ID 를 가리킨다.
- 작업 목록과 진행 기록은 문서에 쓰지 않는다 (이슈와 작업 항목이 정본).
