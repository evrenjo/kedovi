  • 명령과 확인 순서는 설치 한 곳에 있다. 새 버전은 같은 설치 명령을 다시 실행한다.
  • AI 게이트웨이(여러 회사 모델을 한 주소로 주는 서버)를 쓰면 init·install 의 "AI 연결 방식" 에서 고른다. 킷이 이 PC 설정에서 찾아 모델 목록을 조회한다 (5절). 키 값은 저장하지 않는다. 팀 설정(workspace.json)에서 온 게이트웨이는 https(또는 이 PC 안 주소)여야 하고, kedovi start 가 처음 한 번 "팀 설정(workspace.json)의 게이트웨이로 키를 보낼까요?" 를 묻는다 (처음 보는 주소면 아니오). 승인은 이 PC(.agents/local.json)에 남는다. 공유 파일 한 줄 수정으로 키가 다른 서버로 가지 않게 하려는 것이다. 연결 방식을 정하지 않은 워크스페이스는 서비스 직접으로 본다. 이 PC 의 Claude Code 가 게이트웨이로 이어져 있으면 kedovi ai show · kedovi doctor 가 그 주소를 알리고 kedovi ai gateway 로 맞추라고 한다.
