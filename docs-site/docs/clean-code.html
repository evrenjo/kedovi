클린 코드 규칙

원본 clean-code.md

repo 에 감지된 언어마다 클린 코드 규칙이 붙는다. 언어 공통 규칙(clean-code)과 언어별 규칙(lang-*), 프레임워크별 레이어 책임 규칙(스택 팩)이 함께 걸린다. 모든 규칙은 그 repo 의 기존 관례 · 포매터 · 린터 설정이 먼저이고, 관례가 없을 때의 기본값이다.

repo 마다 다르게#

하고 싶은 것방법
한 repo 에서 언어 규칙 끄기kedovi rules off lang-java--10-java --repo <이름>
한 repo 만 우리 규칙으로packs/project/rules/<이름>.md 머리말에 replaces: lang-java--10-java + repos: <이름>
모든 repo 를 우리 규칙으로위에서 repos: 를 뺀다

자세한 형식은 팩 제작.

검사 도구#
