원본 workflow.md

팀 리더(워크스페이스를 만드는 사람)와 팀원(합류하는 사람)이 무엇을 고르고, 그 선택이 어디에 저장되는지를 처음부터 끝까지 그린다. 화면의 질문 문구는 실제 선택 화면(bin/kedovi.js)과 같다.

이 문서는 선택 화면·명령과 한 쌍이다. 질문·선택지·저장 위치를 바꾸면 같은 커밋에서 고친다. npm test 가 코드의 질문 문구와 명령이 이 문서에 모두 있는지 검사한다.
