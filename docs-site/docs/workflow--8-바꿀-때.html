명령하는 일
kedovi list이 PC 에서 만들거나 쓴 워크스페이스 목록
kedovi help [번호|명령|--all]명령 도움말: 분류별로 보기 (kedovi --help 는 자주 쓰는 명령 · 분류 목록만)
kedovi sync정본(packs/·workspace.json)으로 생성물을 다시 만든다
kedovi check생성물이 정본과 같은지 (pre-commit 이 부른다)
kedovi doctor설치·설정 진단, 메모리(Claude Code 세션 · 남은 브라우저 · MCP · Docker VM)
kedovi notify setup알림 설정 화면: 알림 수준(전체 · 결과와 결정 · 진행 현황 · 끄기) · 양방향 대화 · 자리 비움 · 개인 봇 · 팀 방 · 고급
kedovi notify my remote done|quiet|send리모트 컨트롤로 Claude 앱에 이어진 세션: done = 작업 끝만 텔레그램(기본, 결정은 앱이 알린다) · quiet = 쉼 · send = 모두
kedovi notify my desk <초>|offPC 앞이면(그 안에 키보드 · 마우스를 만짐, 기본 120초) 요청 결과 · 위임 끝 · 음성 알림을 보내지 않는다. 결정 대기는 보낸다
kedovi notify my voice on|off음성 알림: 결정 질문(기본) · 끝남 보고를 읽어 음성 메시지로 (scope · name <목소리> · test). 대화로 "음성 켜줘" 도 된다
kedovi notify [my|team …]화면 없이 같은 일: my level · my away · my setup · my channel on 은 봇 토큰을 숨김 입력으로 받는다 (봇 바꾸기 --new). my channel on 은 양방향 대화(기본 꺼짐, 프로젝트마다 전용 봇, kedovi start 가 --channels 를 붙인다)
kedovi handoff find <작업>핸드오프 기록 찾기 (check · index · archive · organize 도)
kedovi budget report시간 예산 월간 집계: 끝낸 작업 수 · 예산 초과율 · 걸린 시간 중앙값 (--month YYYY-MM, 이력은 이 PC 만)
kedovi defects report운영 결함 월간 집계: 분류별 건수 · 잠복 · 해소 시간 (check 는 발견 · 분류 · 해소 칸 검사)
kedovi team-mode
