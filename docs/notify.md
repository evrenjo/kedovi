# 메신저 알림 (텔레그램)

알림은 채널 두 개로 나눈다. 개인 알림이 팀 방을 시끄럽게 하지 않는다.

| 채널 | 받는 곳 | 보내는 것 | 정하는 곳 |
|---|---|---|---|
| 개인 | 내 봇과의 1:1 대화 | 아래 알림 수준대로 | 이 PC (`.agents/local.json`). 팀 기본 `vars.notify.level` |
| 팀 | 팀 그룹방 | 핸드오프 push · 설정 변경 push(`workspace.json` · `packs/` · `bin/`) · 공지 | `vars.notify.teamChat` · `vars.notify.team` (`workspace.json`) |

**설정은 `kedovi notify setup` 화면 하나로 한다** (지금 값이 옆에 보이고, 이미 한 것은 바꾸기 · 제거). 개인 알림은 세 가지만 정하면 된다.

| 설정 | 값 | 뜻 |
|---|---|---|
| 알림 수준 | 전체 · **결과와 결정 (기본)** · 진행 현황 · 끄기 | 텔레그램으로 얼마나 받을지 |
| 양방향 대화 | 켜기 · 끄기 | 텔레그램에서 지시하고 답한다 (아래). 권한 확인 버튼 포함 |
| 자리 비움 | 켜기 · 끄기 | 결정을 텔레그램 버튼 질문으로 보내 텔레그램에서 결정. 결과는 걸린 시간과 상관없이 보낸다. 켤 때 알림이 꺼져 있으면 「결과와 결정」 으로 켠다 |
| 리모트 컨트롤 | **작업 끝만 (기본)** · 쉼 · 모두 | 세션이 리모트 컨트롤로 Claude 앱에 이어져 있으면 결정 · 입력 대기는 앱이 알리고, 텔레그램은 「모든 작업 끝」 한 줄만 보낸다. 자리 비움이어도 결정은 질문 창으로 묻는다. `kedovi notify my remote done\|quiet\|send` |
| PC 앞이면 생략 | **2분 (기본)** · 1분 · 5분 · 끄기 | 그 안에 키보드 · 마우스를 만졌으면 PC 앞으로 보고 요청 결과 · 위임 끝 · 에이전트 진행 · 음성을 보내지 않는다. 결정 대기 · 전체 수준 · 자리 비움은 그대로 (macOS) |
| 음성 | 켜기 · **끄기 (기본)** | 결정 질문을 짧게 읽어 음성 메시지로도 보낸다 (기본 범위 결정 질문만, 아래) |

| 받는 것 | 전체 | 결과와 결정 | 진행 현황 | 끄기 |
|---|---|---|---|---|
| 팀원 승인 대기 (팀 모드 팀원 창의 승인 · 입력 질문, 리더 화면에 안 보임) | ✓ | ✓ | ✓ | - |
| 결정 대기 (질문 · 권한 확인) | 질문 · 보기 | 자리 비움: 질문 · 보기 · 자리에 있음: "선택할 것이 있습니다" 한 줄 | 같음 | - |
| 요청 결과 | 질문 · 답 전문 (모든 요청) | 자리 비움: 답 앞부분 800자 · "전문은 터미널" (모든 요청) · 자리에 있음: "모든 작업 끝" 한 줄 (60초 넘게 걸린 요청, 일하는 팀원 · 백그라운드 작업이 남았으면 보내지 않는다) | 같음 | - |
| 에이전트 시작 · 끝 · 대기 · 위임 끝 | ✓ | - | 자리 비움일 때 | - |
| 끝남 알림의 남은 것 한 줄 (일하는 팀원 · 대기 팀원 · 리더의 백그라운드 작업 수, 있을 때만) | ✓ | 자리 비움일 때 | 자리 비움일 때 | - |
| 진행 현황 (입력 없이 5분마다) | ✓ | - | 자리 비움일 때 | - |
| 채널 끊김 경고 | ✓ | ✓ | ✓ | ✓ |

- 메시지는 텔레그램 형식으로 바꿔 보낸다 (표는 `• 항목: 내용` 목록, 굵게 · 코드 · 링크 · 인용, 제목 앞 빈 줄). 긴 보고는 앞부분만 보이고 나머지는 눌러서 펼친다(접히는 인용).
- **자리 비움 결정 질문**: 머리 메시지(몇 건 · 답하는 법) + **결정마다 메시지 하나**(굵은 제목 · 배경 인용 · ✅ 권장안 · ▫️ 다른 보기) + 입력창 아래 **답 버튼**: 보기마다 한 줄에 보기 이름까지(`1-1 ✅ 폰 3종 확인 후 푸시` · `1-2 바로 푸시` · `1 ✏️ 직접 입력` · `모두 권장안`). 버튼을 누르거나 `1-1, 2-1` 처럼 쓴다. 보기에 없으면 `1 ✏️ 직접 입력` 을 눌러 열리는 입력창에 쓰거나 `2: 원하는 내용` 처럼 쓴다. 버튼은 한 번 누르면 접히고(입력창 옆 ⌨ 로 다시 연다) 늘 떠 있지 않는다. 답을 다 받으면 걷고, 에이전트가 걷는 것을 잊어도 답을 받은 뒤 작업이 끝나면 끝남 알림이 걷는다. 에이전트가 결정을 터미널 글로만 묻고 끝내려 하면(번호 보기 + 묻는 말인데 이번 요청에 버튼 질문을 안 보냄) 훅이 한 번 막고 버튼 질문으로 보내게 한다.
- **음성**: 켜면 결정 질문("결정 다섯 건. 첫째, … 권장은 …")을 짧게 읽어 음성 메시지로 보낸다. 끝남 보고도 읽게 하려면 `voice scope both`. 표 · 코드 · 경로는 읽지 않는다. macOS 기본 도구(`say` · `afconvert`)로 만들고, 그 밖 OS 는 `espeak-ng` · `ffmpeg` 가 있을 때만. 목소리 기본은 Yuna. 범위 · 목소리는 `kedovi notify my voice …` 또는 대화("음성 켜줘" · "결정만 음성으로" · "목소리 남자로")로 바꾼다.
- 고급: 결과 알림 기준(기본 60초) · PC 앞이면 생략(기본 2분) · 진행 현황 간격(기본 5분). 화면의 "고급".
- 세션 안에서 "자리 비울게" · "돌아왔어" · "알림 줄여줘" · "음성 켜줘" 처럼 말해도 Claude 가 바꾼다. 바로 적용된다.

| 화면 없이 (AI 가 바꿀 때) | 명령 (`kedovi notify my …`) |
|---|---|
| 개인 봇 연결 | @BotFather 에서 봇을 만들고 봇에게 아무 말이나 보낸 뒤 `setup` (토큰은 숨김 입력이라 셸 기록에 남지 않는다. 봇 바꾸기는 `setup --new`. 알림 수준은 결과와 결정으로 켠다. 켜지 않으려면 `--no-on`). 개인 봇은 프로젝트 양방향 채널 봇과 따로 둔다. 같으면 다른 워크스페이스 알림이 그 프로젝트 대화방으로 섞여 `kedovi notify` 가 ⚠ 로 알린다 |
| 수준 · 자리 비움 · 기준 | `level all\|decisions\|progress\|off` · `away on\|off` · `remote done\|quiet\|send`(리모트 컨트롤 연결 중 텔레그램) · `min <초>` · `desk <초>\|off`(PC 앞이면 끝남 알림 생략) · `channel progress <분\|off>` · `reset`(팀 기본 따름) |
| 음성 | `voice on\|off` · `voice scope both\|decisions\|done\|all`(결정+끝남 · 결정만(기본) · 끝남만 · 모두) · `voice name <목소리>` · `voice test` |
| 양방향 대화 | `channel on` (프로젝트 봇 토큰은 숨김 입력. 봇 바꾸기는 `channel on --new`) · `off` · `remove` · `status` |
| 봇 제거 · 시험 | `remove` · `test` |
| 팀 봇 · 팀 방 (`kedovi notify team …`) | 팀원마다 `setup` (팀 봇 토큰은 숨김 입력) · 팀장이 `chat <그룹방 ID>` → commit · push · `announce "<내용>"` · `test` |

**양방향 대화 (텔레그램 채널)**: 이 프로젝트 전용 봇에게 보낸 메시지가 Claude Code 세션에 들어오고 답이 같은 대화로 온다. Claude Code 공식 telegram 플러그인(연구 미리보기)을 쓰며 **개인 · 이 PC · 프로젝트마다** 따로 켠다 (팀 봇 · 팀 방은 쓰지 않는다).

| 항목 | 내용 |
|---|---|
| 켜기 | 텔레그램 @BotFather 에서 이 프로젝트용 봇을 만들고 봇에게 아무 말이나 보낸 뒤 `kedovi notify my channel on` (봇 토큰은 숨김 입력). 확인한 것을 한 줄씩 보여 준다: 연결 방식 · Claude Code · Bun · 봇 이름 · 내 채팅 · 플러그인 · 상태 폴더 |
| 플러그인 설치 범위 | **이 워크스페이스 전용(local)**: `.claude/settings.local.json` 에 켜져 이 PC · 이 워크스페이스 세션만 서버를 띄운다. `channel on` 이 local 로 설치하고, user 범위 설치(이 PC 모든 세션이 서버를 띄움)와 워크스페이스 안 다른 폴더의 설치는 지운다 |
| 프로젝트마다 | 봇 하나는 한 곳에서만 메시지를 받으므로 프로젝트마다 다른 봇을 쓴다. 상태 폴더(토큰 · 허용 목록)는 `~/.claude/channels/telegram-<프로젝트>/`. 다른 프로젝트가 쓰는 봇이면 거부한다 |
| 알림 | 채널을 켠 워크스페이스는 개인 알림도 그 봇으로 온다. 프로젝트마다 대화가 나뉘어 섞이지 않는다 |
| 시작 | `kedovi start` 가 Claude Code 로 시작할 때 `--channels plugin:telegram@claude-plugins-official` 와 상태 폴더를 붙인다. 준비가 안 됐으면 알리고 채널 없이 시작한다. 이번만 빼기: `kedovi start --no-channel` |
| 허용 | 내 채팅만 허용(allowlist)한다. 페어링 코드는 필요 없다 |
| 필요한 것 | [Bun](https://bun.sh) (플러그인 서버가 Bun 으로 돈다), claude.ai 로그인 또는 Console API 키 (AI 게이트웨이 · Bedrock 등은 안 된다). Team · Enterprise 조직은 팀장이 채널을 켜야 한다 |
| 권한 확인 | 플러그인이 텔레그램 버튼으로 보낸다 (승인 · 거부). 이때 kedovi 의 "권한 확인 대기" 알림은 보내지 않는다 |
| 양쪽 같은 내용 | 텔레그램에서 온 요청은 Claude 가 텔레그램에 보낸 답을 터미널에도 그대로 쓴다. 터미널 요청이 텔레그램에 얼마나 가는지는 알림 수준대로 |
| 선택지 | 기본은 터미널 선택지 창(방향키 · 권장안 첫째 · 직접 입력)이고 텔레그램에는 질문과 선택지가 간다 (창은 터미널에서만 답할 수 있다). 자리 비움이면 결정을 텔레그램 버튼 질문(`notify.js ask`)으로 보내 버튼 · 번호 · 직접 입력(✏️)으로 답한다 |
| 한계 | 세션이 열려 있을 때만 받는다. 같은 프로젝트 세션을 두 개 띄우면 나중 세션만 받는다 |
| 진행 상황 | 에이전트가 일하는 동안 텔레그램에서 물으면 Claude 가 누가 무엇을 하는지 바로 답한다 |
| 끊김 감시 | 요청마다 · 끝날 때 수신 상태를 본다. 끊기면 텔레그램과 터미널에 한 번 알리고(`/mcp` → plugin:telegram → Reconnect, 안 되면 `kedovi start -c`), 다시 붙으면 알린다. 세션 안에서 AI 가 플러그인을 다시 켤 수는 없다 |
| 끊김 원인 | 같은 봇을 두 곳이 받으면 서로 끊는다. `channel on` 이 플러그인을 local 로 두고 기본 폴더(`~/.claude/channels/telegram`)의 같은 토큰을 끄며, 위임 세션은 서버를 띄우지 않는다. `kedovi doctor` 가 남은 충돌을 알려 준다 |
| 팀원 막기 | 팀원 세션(tmux)은 리더 환경을 물려받아 같은 봇 서버를 띄우고 리더 서버를 끈다. `kedovi start` 가 채널 세션의 PATH 앞에 `bun` 대리 실행(상태 폴더의 `kedovi-bin/bun`)을 두어 `--channels` 로 시작한 세션만 서버를 띄우고, 팀원 · 위임 · 채널 아닌 세션은 막는다. 띄움 · 막음은 상태 폴더의 `kedovi-channel.log` 에 한 줄씩 남고, 끊김 알림에 마지막 기록과 수신을 가져간 쪽(팀원 이름 · pid)을 붙인다 |

- 토큰과 개인 채팅 ID 는 repo 밖 `~/.config/kedovi/telegram.env`(권한 600)에 둔다. 팀 봇 토큰은 repo 에 올리지 않고 따로 전달한다.
- 팀 알림은 워크스페이스의 `pre-push` 훅이 모으고, push 가 원격에 반영된 뒤 따로 보낸다. push 를 막거나 늦추지 않고, push 가 실패하면 보내지 않는다.
- 스크립트가 부르는 보내기 명령(`notify.js say` · `ask` · `prompt` · `answered` · `announce` · `test`)은 종료 코드로 결과를 알린다: 0 보냄 · 1 전송 실패(텔레그램 API 거부 · 네트워크) · 2 설정 없음(봇 토큰 · 채팅 · 팀 방) · 3 사용법 오류. 훅과 push 뒤 팀 알림은 실패해도 세션 · push 를 막지 않는다.
- Claude Code · Codex 모두 요청 결과를 알린다. 결정 대기(질문 · 권한 확인) 알림은 Claude Code 에만 있다. 오래 걸린 역할 위임(`delegate.js`)이 끝나도 알린다. 잠깐 끄려면 `KEDOVI_NOTIFY=0`.
